A small deterministic forecaster (Node 22, standard library only) for GTA VI's launch-day Twitch viewers. Given hour 1's
print, it forecasts each later hour as `print_1 * exp(rho_h)`, where `rho_h` is the log-ratio "hour h / hour 1" on the
same UTC release day of past big launches. Console-first, single-player, midnight-local launches are weighted most, and
launches whose pre-release ramp looks like this one's are weighted more. The five quantiles come from the weighted,
kernel-smoothed mixture of those log-ratios, which suits the log-scale pinball loss.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
